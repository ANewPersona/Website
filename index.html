How to Use:

  • Click buttons to add widgets
  • Drag widgets to move them
  • Click text to edit it
  • Hover & click ✕ to delete
  • 🎵 Add songs via YouTube search
  • 💾 Save Layout (JSON) - saves positions & data
  • 📥 Save Collage (HTML) - saves everything including images!
  • 📂 Load Layout - restore a saved JSON layout
  • Have fun creating! 🎨
